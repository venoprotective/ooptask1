# Library Catalog | TASK 1 OOP

Небольшой проект на Java для работы с библиотекой.

В проекте реализованы книги, авторы, физические экземпляры книг и их расположение в библиотеке. Книги находятся на полках, полки в шкафах, а шкафы в комнатах.

Через `LibraryCatalog` можно:

- добавлять книги и экземпляры;
- искать книги по названию, автору, ISBN и жанру;
- получать расположение экземпляра;
- выдавать и возвращать книги;
- смотреть выданные и просроченные книги;
- смотреть историю по книге или читателю;
- переносить полки и шкафы;
- получать статистику по жанрам и заполненности полок.

## Основные классы

`Author`: хранит информацию об авторе книги: имя и фамилию.

`Book`: описание самой книги. Содержит ISBN, название, автора и жанр.

`PhysicalBook`: конкретный физический экземпляр книги. У него есть инвентарный номер, состояние и полка, на которой он находится.

`LibraryCatalog`: основной класс проекта. Хранит книги и экземпляры и содержит методы для поиска, выдачи, возврата и получения статистики.

`Loan`: информация о выдаче книги читателю. Хранит читателя, дату выдачи, срок возврата и фактическую дату возврата.

`Room`: комната библиотеки. Содержит список шкафов.

`Cabinet`: шкаф, который находится в комнате и содержит полки.

`Shelf`: полка со списком физических экземпляров книг.

`StorageAddress`: используется для получения полного расположения книги: комната, шкаф и полка.

`Genre`: enum с возможными жанрами книг.

`BookState`: enum для состояния физического экземпляра книги: `NEW`, `OLD` или `LIKENEW`.

`BookAlreadyIssuedException`: ошибка, которая возникает при попытке выдать экземпляр, который уже выдан.

`BookNotIssuedException`: ошибка при попытке вернуть экземпляр, который сейчас не был выдан.

`Main`: создаёт тестовые данные и запускает проверки работы программы.

## Тесты

Отдельного JUnit в проекте нет. Простые тесты находятся прямо в `Main.java`.

Сейчас там есть 5 тестов:

- `test1()` - проверка поиска книг;
- `test2()` - проверка адресов экземпляров;
- `test3()` - выдача и возврат книги;
- `test4()` - просроченные книги и история выдач;
- `test5()` - перенос полок и шкафов, а также статистика.

Все тесты вызываются из метода `main()`.

### Запуск через IntelliJ IDEA

1. Открыть проект в IntelliJ IDEA.
2. Открыть `src/library/Main.java`.
3. Запустить метод `main`.
4. Результаты тестов появятся в консоли.

### Запуск через консоль

Нужно находиться в корневой папке проекта.

Сначала скомпилировать файлы:

```bash
javac -d out src/library/*.java
```

После этого запустить:

```bash
java -cp out library.Main
```

В консоли будут по очереди выведены результаты `TEST1` - `TEST5`.

Для проекта желательно использовать Java 17 или новее.
