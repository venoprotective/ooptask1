# Library Catalog

Учебный проект по ООП на Java. Здесь реализован небольшой библиотечный каталог: можно хранить книги и их физические экземпляры, искать их, учитывать расположение в библиотеке и оформлять выдачу читателям.

Проект сделан без базы данных и интерфейса — вся логика находится в Java-классах и проверяется тестами.

## Что умеет каталог

`LibraryCatalog` позволяет:

- добавлять книги и физические экземпляры;
- искать книгу по ISBN, названию, автору или жанру;
- находить экземпляр по инвентарному номеру;
- получать его расположение в библиотеке;
- выдавать и возвращать книги;
- смотреть текущие и просроченные выдачи;
- получать историю выдач по книге или читателю;
- перемещать полки между шкафами и шкафы между комнатами;
- считать количество экземпляров по жанрам и заполненность полок.

## Как устроено хранение книг

Физическое расположение книги описывается простой иерархией:

```text
Room
└── Cabinet
    └── Shelf
        └── PhysicalBook
```

`Book` описывает само издание: ISBN, название, автора и жанр. `PhysicalBook` — конкретный экземпляр этой книги с отдельным инвентарным номером и состоянием.

Выдача книги хранится в `Loan`. В ней есть читатель, дата выдачи, срок возврата и фактическая дата возврата.

## Основные классы

- `LibraryCatalog` — основная логика каталога.
- `Book` — книга как издание.
- `PhysicalBook` — конкретный экземпляр книги.
- `Author` — имя и фамилия автора.
- `Loan` — информация о выдаче экземпляра читателю.
- `Room`, `Cabinet`, `Shelf` — физическое расположение экземпляров.
- `StorageAddress` — адрес экземпляра: комната, шкаф и полка.
- `Genre` — жанр книги.
- `BookState` — состояние экземпляра: `NEW`, `OLD` или `LIKENEW`.
- `BookAlreadyIssuedException` — попытка повторно выдать уже выданный экземпляр.
- `BookNotIssuedException` — попытка вернуть экземпляр, который не был выдан.


## Тесты

Тесты находятся в `test/library/LibraryCatalogTest.java` и написаны на JUnit 5.

Они проверяют поиск книг, работу с экземплярами, выдачу и возврат, просроченные книги, историю выдач, перемещение полок и шкафов, а также статистику каталога.

Запустить тесты можно из корня проекта:

```bash
mvn test
```

Также их можно запускать прямо из IntelliJ IDEA через класс `LibraryCatalogTest`.

## Требования

- Java 17 или новее;
- Maven.

Версия Java указана в `pom.xml` через `maven.compiler.source` и `maven.compiler.target`.

## Запуск

У проекта сейчас нет отдельного консольного приложения с `main`-методом. Это набор классов с библиотечной логикой, поэтому основной способ проверить работу проекта — запустить тесты:

```bash
mvn test
```
